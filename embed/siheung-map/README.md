# 시흥 배움지도 — 유지보수 업체 전달용 안내

시흥교육캠퍼스 쏙(SSOC)에 iframe으로 탑재할 지도 기반 장애인 평생교육기관 안내 화면입니다.
**이 폴더의 파일을 그대로 정적 호스팅한 뒤, 쏙의 해당 페이지에 iframe 한 줄을 넣으면 됩니다.**

---

## 1. 파일 구성

| 파일 | 역할 | 누가 고치나 |
|---|---|---|
| `index.html` | 화면 전체(지도·필터·목록·상세). 외부 라이브러리 없음 | 업체 |
| `data.json` | 기관 데이터. 운영 중 갱신 대상 | **시청 담당자** |
| `README.md` | 이 문서 | — |

현재 `index.html`은 데이터를 파일 안에 들고 있습니다(`<script id="dataset">` 블록).
담당자가 HTML을 건드리지 않고 데이터만 갱신하려면 아래 2번으로 분리하세요.

## 2. 데이터 분리 (권장)

`index.html`의 `<script type="application/json" id="dataset">` 블록을 지우고, 스크립트 시작 부분을 이렇게 바꿉니다.

```js
fetch("data.json?v=" + Date.now())
  .then(function (r) { return r.json(); })
  .then(function (DATA) { start(DATA); });
```

이후 담당자는 `data.json`만 교체하면 화면이 갱신됩니다.
스프레드시트로 관리하다가 CSV → JSON 변환해 올리는 방식도 가능합니다(항목 이름만 맞추면 됩니다).

## 3. 탑재 방법 (iframe)

쏙 페이지에 넣을 코드입니다.

```html
<iframe
  src="https://<호스팅주소>/siheung-map/index.html"
  title="시흥 배움지도 — 장애인 평생교육기관 찾기"
  width="100%" height="1100" loading="lazy"
  style="border:0; display:block; width:100%;">
</iframe>
```

- `title` 속성은 **필수**입니다. 화면낭독기 사용자가 이 iframe이 무엇인지 알 수 있는 유일한 단서입니다.
- `scrolling="no"`는 넣지 마세요. 높이 계산이 어긋나면 내용이 잘립니다.

### 높이 자동 맞춤 (선택하지만 권장)

내부 화면은 필터 결과에 따라 높이가 변합니다. 부모 페이지(쏙)에 아래 스크립트를 추가하면 iframe 높이가 따라옵니다.

```html
<script>
window.addEventListener("message", function (e) {
  // 운영 시 반드시 호스팅 주소로 제한하세요
  if (e.origin !== "https://<호스팅주소>") return;
  if (!e.data || e.data.type !== "ssoc-map-height") return;
  document.querySelector("iframe[title^='시흥 배움지도']").style.height = (e.data.height + 24) + "px";
});
</script>
```

내부 화면은 이미 `postMessage({type:"ssoc-map-height", height:…})`를 보내고 있습니다.
부모 스크립트를 넣을 수 없다면 `height="1100"` 고정으로 두고, 모바일에서 잘리지 않는지만 확인해 주세요.

## 4. 도식 지도 → 실제 지도로 교체

현재 배경은 위치 감각만 주는 **도식(SVG)**입니다. 실제 지도로 바꿀 때:

| 선택지 | 비용 | 특징 |
|---|---|---|
| **카카오맵 JS API** | 무료(일 한도) | 국내 주소 검색·길찾기 연계가 자연스러움. JS 키에 **호스팅 도메인 등록 필요** |
| **브이월드(국토교통부)** | 무료 | 공공 서비스에 적합, 공공 데이터 연계 용이. 인증키에 도메인 등록 필요 |
| 네이버 지도 API | 무료(한도) | 사용량 초과 시 과금 주의 |

데이터의 `lat`/`lng`를 그대로 쓰기 때문에 **교체해도 데이터 구조는 바뀌지 않습니다.**
`index.html`의 `project()` 함수와 SVG 블록만 지도 API 초기화 코드로 바꾸면 됩니다.

좌표가 없는 기관은 도로명주소를 좌표로 바꿔야 합니다(카카오·브이월드 지오코딩 API, 또는 공공데이터포털 주소 변환 서비스).

## 5. 접근성 — 이 화면에서 지켜야 하는 것

장애인 대상 서비스이므로 아래는 **선택이 아니라 요구사항**입니다. 개편·검수 시 확인해 주세요.

- **지도에 있는 정보는 목록에도 전부 있어야 합니다.** 지도는 보조 수단이고, 목록이 정본입니다. (현재 구현은 이 원칙을 따릅니다)
- 마커는 `<button>`으로 만들어 **키보드 Tab으로 접근**되고, 초점 표시가 눈에 보여야 합니다.
- 마커 `aria-label`에 기관명·동·강좌 수를 넣어 화면낭독기에서 의미가 전달되게 합니다.
- 색만으로 상태를 구분하지 않습니다(배지에 항상 글자 병기).
- 200% 확대에서 레이아웃이 깨지지 않아야 합니다.
- 확인되지 않은 정보는 비워두지 말고 **「정보 확인 필요」로 표시**합니다. (정보 없음 ≠ 지원 없음)

## 7. 태블로를 쓰지 않은 이유

태블로(Tableau Public)로도 지도 대시보드를 만들 수 있지만, 이 용도에는 맞지 않습니다.

- 무료 버전은 **데이터가 전부 공개**되고, 워크북이 태블로 서버에 올라갑니다.
- 화면낭독기·키보드 접근 대응이 약해 **웹 접근성 기준을 맞추기 어렵습니다.**
- 모바일에서 한국어 레이블이 깨지거나 잘리는 경우가 많습니다.
- 외부 서비스 장애 시 쏙 페이지에 빈 영역이 남습니다.

이 화면은 **단일 HTML 파일 + JSON**이라 외부 의존이 없고, 접근성 요구사항을 직접 만족시킬 수 있으며,
업체 입장에서도 정적 파일 업로드로 끝납니다.

## 8. 업체에 요청할 항목 (체크리스트)

- [ ] `embed/siheung-map/` 폴더를 쏙과 같은 도메인 또는 하위 도메인에 정적 호스팅
- [ ] 지정 페이지에 iframe 삽입 (`title` 속성 포함)
- [ ] 부모 페이지에 높이 조정 스크립트 추가, `e.origin` 검사 포함
- [ ] 카카오맵 또는 브이월드 키 발급 및 **호스팅 도메인 등록**, 도식 지도 교체
- [ ] `data.json`을 담당자가 직접 교체할 수 있는 경로·권한 부여
- [ ] 모바일(가로 360px)·키보드 전용·화면낭독기 3가지 조건에서 동작 확인
- [ ] 캐시 설정: `data.json`은 짧게(혹은 `?v=` 파라미터), `index.html`은 일반 캐시

**현재 데이터는 형식 설명을 위한 예시입니다.** 실제 기관명·주소·연락처·강좌 수·편의지원 범위는
담당 부서 확인 후 `data.json`을 교체해 주세요.
